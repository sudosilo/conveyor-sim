Conveyor Sim changelog

2026-11-21, v2026.11.21b. Stripped out the agent world: API, contributions, keys, rules, scoring and the city demo are gone. The site is now a static visual builder. Four examples (Packet Works, Photo Gallery Site, Login and Pay, Challenge: Feed from Clocks), a Build mode to place, connect, rename and delete machines, live counts, a saved build in the browser and share links that hold the whole plan.

2026-11-21, v2026.11.21. Built the packet factory. Added the factory layer with place_machine and place_conveyor, 16 machine types that each stand for a part of a website, a live packet simulation using Packet Baron's 160 sauces, 7 wrapper styles and 50/50 packets, a flat isometric view that is now the default, tap to read any machine, the example factory Packet Works, factory points in the score, and Mission 3 in the rules. Pointed the API and submit script at this repository instead of the agent test bed.

2026-10-28, v2026.10.28. First release. Started the conveyor simulation as a copy of the agent test bed.
